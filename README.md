# Iraqi Business AI | الذكاء الاصطناعي لأعمال العراق

یک پروژه برای کمک به راه‌اندازی و مدیریت کسب‌وکارهای کوچک و متوسط در عراق، با کمک هوش مصنوعی.
مشروع لمساعدة أصحاب المشاريع الصغيرة والمتوسطة في العراق على التخطيط والإدارة.

## اهداف پروژه

- ارزیابی ایده‌های کسب‌وکار متناسب با بازار عراق
- تهیه طرح کسب‌وکار (Business Plan) به‌صورت ساختاریافته
- محاسبه ساده هزینه، درآمد و نقطه سر‌به‌سر
- پشتیبانی از زبان‌های فارسی، عربی و انگلیسی

## ساختار مخزن

```
.
├── README.md
├── docs/
│   ├── business-ideas.md      # حوزه‌های فعالیت و ایده‌های کسب‌وکار
│   └── business-plan.md       # قالب طرح کسب‌وکار
└── tools/
    └── breakeven.py           # ابزار محاسبه نقطه سر‌به‌سر
```

## استفاده از ابزار محاسبه

```bash
python3 tools/breakeven.py --fixed 5000 --price 25 --variable 10
```

- `--fixed`: هزینه‌های ثابت ماهانه
- `--price`: قیمت فروش هر واحد
- `--variable`: هزینه متغیر هر واحد

واحد پول دلخواه است (دلار آمریکا یا دینار عراقی)، فقط در هر سه مقدار یکسان باشد.

## نکته مهم

اطلاعات این مخزن جنبه راهنمایی عمومی دارد. قوانین ثبت شرکت، مالیات و مجوزها تغییر می‌کنند؛
پیش از اقدام، آن‌ها را از مراجع رسمی عراق یا یک مشاور حقوقی بررسی کنید.
